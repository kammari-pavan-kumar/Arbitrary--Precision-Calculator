---------------------------------------------------------Arbitrary Precision Calculator (APC)------------------------------------------------
Project Title : Arbitrary Precision Calculator (APC)
Project Info  : The Arbitrary Precision Calculator is a software application designed to perform high-precision mathematical calculations.
                it handles numbers of infinite length using Doubly Linked Lists
                1. It supports: Basic arithmetic operations
                2. Arbitrary precision calculations
                3. Large integer and decimal handling
                4. Precision control
                5. Error-free decimal arithmetic
                Arbitrary precision arithmetic allows calculations with very large numbers and very small decimals without losing accuracy.
                Arithmetic Operations performed in this project are 
                ->Addition
                ->Subtraction
                ->Multiplication
                ->Division
